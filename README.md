# Design Gallery

本地可试玩的游戏参考库。首页按游戏名称、展厅标题和标签搜索，进入展厅后可切换游戏、复位场景、暂停或半速观察。每款游戏的按键见场景下方。

| 展厅 | 游戏 |
| --- | --- |
| 第一人称桌面交互 | 恶魔轮盘、骗子酒吧 |
| 侧视角色动作 | 泰拉瑞亚、空洞骑士、蔚蓝、死亡细胞、Leap Day、武士零 |
| 俯视移动与瞄准 | 土豆兄弟、挺进地牢、以撒的结合、饥荒、脱逃者 2 |
| 斜俯视角色动作 | 哈迪斯、风中行者 |

## 本地启动

在仓库根目录运行，使用 Node.js 20 或以上版本，无需安装依赖或构建。

```sh
npm start
```

打开 <http://127.0.0.1:4317/>。按 Ctrl+C 停止。也可用 `node serve.mjs --port 4318` 指定端口。服务仅监听本机，试玩所需模型、贴图、音效和脚本随仓库提供。

## 维护馆藏

- `catalog.mjs` 管理首页展厅、封面、搜索标签和首次收录日期。
- `assets/character-lab/v1/exhibits/<游戏 ID>/` 保存可玩的场景和资源。同级的 `hall-catalog.mjs` 管理展厅归属、入口、操作说明和来源链接，`collection.json` 记录收录的游戏 ID。
- 添加游戏时复制已验收版本，更新对应清单和首页标签，再运行以下检查。从首页搜索游戏，进入展厅，切换标签并操作角色或桌面物件。

```sh
node scripts/sync-posts.mjs
npm run check
```
