# 泰拉瑞亚角色动作

2026-11-16 用户确认收录。展示版沿用本机已确认的角色、动作、场地和操作。

原角色图层与十四帧步态，固定经典角色和单钩。控制与动作参数按锁定参考重建。

## 操作

- W A S D：方向
- Space / K：跳跃 / 脱钩
- S：平台下穿
- 鼠标：钩爪瞄准
- I / 右键：发射 / 收回钩爪
