# 哈迪斯 · 基础剑走位与冲刺斩

[进入试玩](harness.html) · [原版与试玩动作对照](v3/comparison.html) · [上一版试玩](harness-v2.html)

WASD 走位，鼠标瞄准，J 或左键普攻，L 或空格冲刺。冲刺中按攻击可触发冲刺斩。角色模型采用 [Phan21 / RagerGokuda 的 Zagreus 模型](https://sketchfab.com/3d-models/free-3d-model-zagreus-hades-5a9e2892807448cb9e9982fd8cfcdc33)，剑招、跑步和冲刺按参考片段重建。参考片段与剑光素材来源见动作对照页。
