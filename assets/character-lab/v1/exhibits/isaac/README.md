# 以撒的结合角色动作

2026-11-16 用户确认收录。展示版沿用本机已确认的角色、动作、场地和操作。

原始 PNG 与 ANM2 保留头身分向、眼部挂点、普通泪弹与水花。惯性、弹道和声音为本次重建。

## 操作

- W A S D：移动
- ↑ ↓ ← → / I K J L：发射

## 参考与差异

- 加速、松键衰减、反向时间、发射间隔、泪弹速度、速度继承和重力使用明确的重建参数，等待原作带输入录像校准。
- 素材归档含后续扩展资源。本样本使用基础 Isaac 的共享 Walk/Head/Hit 与普通泪弹；Rebirth 安装文件版本字节核对待补。
- 泪弹选用原 ANM2 默认 RegularTear6，水花选用 small Poof。Rebirth 初始配置的实际选档、引擎缩放与颜色处理待原片进一步校准。
- 房间、石头、木靶、慢追踪木偶和木屑为本样本制作。
- 音效为 WebAudio 合成，原版音色和混音待后续制作。
